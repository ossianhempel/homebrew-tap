# homebrew-tap

Homebrew tap for ossianhempel.

## Install

```
brew install ossianhempel/tap/things3-cli
brew install ossianhempel/tap/sl-clie
```

## Update

Formula is generated from the main repo:
- `./scripts/update-brew-formula.sh` (commit-based)
- `./scripts/update-brew-formula.sh --version vX.Y.Z` (release tarballs)
